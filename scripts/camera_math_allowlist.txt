# Screens that have NOT adopted StageViewport / StageCamera yet.

# THIS IS THE DEBT, NAMED. Build 47's viewport track landed the shared constants
# in two screens — the Control tab and the motion editor — and left the rest
# holding their own copies. The plan said in as many words: "This build lands the
# shared constant in two screens and leaves four inconsistent; say so, do not
# paper over it." This file is the saying so. A pass over these prints a count,
# so a green gate can never be mistaken for a converted app.
#
# One entry per line: <file basename>::<pattern tag>. Per FILE and per TAG, never
# per line — four owners edit this tree at once and a line number is stale the
# moment one of them saves.
#
# THE LIST ONLY SHRINKS. Adding an entry to make a new hit go away is the one
# thing it is not for; a new screen writing its own field of view or its own 300
# is the failure this guard exists to catch.
